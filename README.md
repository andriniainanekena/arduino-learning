## Description

A collection of small Arduino projects to learn by practice. The idea is to discover how Arduino works step by step.

## Goal

- Learn the basics of Arduino programming
- Understand simple electronics and wiring
- Understand how software and hardware work together
- Get familiar with embedded systems concepts

## Tools

- Arduino IDE
- Beginner Arduino starter kit
- Tinkercad Circuits
